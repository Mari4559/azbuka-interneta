# 🌐 Азбука интернета — Онлайн

Сетевая игра по цифровой грамотности для детей, подростков и старшего поколения

## Как играть
1. Открой ссылку на игру
2. Нажми «🎮 Создать игру» и получи код комнаты
3. Скинь код друзьям — они подключатся через «🔗 Присоединиться»
4. Отвечай на вопросы, ходи по клеткам и дойди до финиша!

## Особенности
- 🤖 Режим игры с ботом
- ✨ Специальные клетки (Wi-Fi, вирус, пароль и др.)
-  Работает на телефоне и компьютере
